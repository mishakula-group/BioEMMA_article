# External tool comparison

This directory contains the publication-ready artifacts retained for the
external visualization tool comparison.

## Figure 5 matrix

- `tool_comparison_matrix.png` - rendered matrix used for Figure 5.
- `tool_comparison.html` - HTML table generated from the same matrix data.
- `tool_comparison_feature_definitions.md` - feature definitions used to score
  the matrix.

The PNG and HTML table are generated by
`../../scripts/build_tool_comparison_matrix.py`.

## Supplementary S5-S9

- S5: `sammi_full.html` - SAMMI full-map export. The HTML embeds the model data
  but loads the SAMMI viewer scripts from official SAMMI/CDN URLs.
- S6: `fluxer_e_coli_core.svg` and `fluxer_e_coli_core.png` - Fluxer
  visualization output. `fluxer_e_coli_core.html` is a local white-background
  wrapper for the SVG.
- S7: `cave_d_glucose.svg` - CAVE visualization output retained as the vector
  export available in this repository.
- S8: `grohar_output.png` - Grohar visualization output.
- S9: `metexplore_v2_visualization.png` - MetExplore V2 visualization output.

## Other retained comparison artifacts

- `networkx_baseline.png` - NetworkX baseline visualization.
- `fluxer_upload_model.xml` - SBML model for Fluxer GUI upload.
- `model_for_fluxer.json` - COBRA JSON copy of the same model retained for
  compatibility with tools that accept COBRA JSON.

Flux/flow files, duplicate CSV tables, summary files, and temporary source
folders are intentionally not included in this publication bundle.
