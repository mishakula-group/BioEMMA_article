# Supplementary Table S1. Tool descriptions and sources for the functional comparison

Brief tool descriptions were summarized from the corresponding developer pages,
official documentation, or tool publications. The descriptions are intended to
provide context for Figure 5 and do not change the support-level scoring matrix.

| Tool | Source-based brief description | Primary source used |
|---|---|---|
| CytoSEED | Cytoscape plugin for viewing, manipulating, and analyzing metabolic models created by Model SEED; it can organize model reactions into networks based on corresponding KEGG pathway maps. | https://apps.cytoscape.org/apps/cytoseed |
| CAVE | Cloud-based platform for integrated calculation, visualization, examination, and correction of metabolic pathways in genome-scale metabolic models, including published and user-uploaded models. | https://doi.org/10.1093/nar/gkad360 |
| Grohar | Computational tool for automatic identification and visualization of genome-scale metabolic model subnetworks and their metabolic fluxes, with subnetworks specified by metabolites of interest or reference pathways. | https://doi.org/10.1089/cmb.2017.0209 |
| Fluxer | Web application for computing and interactively visualizing flux graphs from genome-scale metabolic models using Flux Balance Analysis, with graph views such as spanning trees, k-shortest paths, and complete graphs. | https://fluxer.umbc.edu/ |
| MetExplore V2 | Online solution for metabolic network curation, network exploration, and omics data analysis, combining interactive tables with metabolic network visualization and over-representation statistics. | https://doi.org/10.1093/nar/gky301 |
| ModelExplorer | Stand-alone graphical application for visual inspection and inconsistency correction of genome-scale metabolic reconstructions, visualizing SBML models as bipartite metabolite-reaction graphs. | https://doi.org/10.1186/s12859-019-2615-x |
| SAMMI | Browser-based Semi-Automated Metabolic Map Illustrator for metabolic network visualization, using interactive force-directed bipartite graphs with automated node positioning and manual editing functions. | https://sammi.readthedocs.io/en/latest/ |
| Escher | Web-based tool for building, viewing, and sharing visualizations of metabolic pathways; it supports maps built from genome-scale metabolic models and visualization of reaction, gene, and metabolite data. | https://escher.readthedocs.io/en/latest/ |
| NAViFluX | Visualization-centric web-browser tool that unifies native pathway/subsystem map generation, interactive model refinement, pathway merging, flux analyses, topology analyses, enrichment analyses, and data overlay within network views. | https://doi.org/10.1093/bioinformatics/btag191 |
| BioEMMA | Python library for building Escher-compatible metabolic maps from KEGG pathway layouts and genome-scale metabolic models, including KGML parsing, BiGG/SEED identifier conversion, Escher JSON output, flux data, summaries, and reproducible output folders. | https://pypi.org/project/bioemma/ |
