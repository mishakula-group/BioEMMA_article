# Supplementary results

This directory contains supplementary materials for the article.

## Contents

- `rn00010/escher_map.html` and `rn00010/escher_map.json` - full BioEMMA `e_coli_core` map for KEGG `rn00010`.
- `rn00010/escher_map_with_fluxes.html` - the same full BioEMMA map with the flux overlay.
- `rn00010/kegg_escher_map.html` and `rn00010/kegg_escher_map.json` - full KEGG reference `rn00010` map exported in Escher format.
- `rn00010/kegg_source_reconstruction.json` - KEGG reconstruction source data used to build the supplementary full map.
- `rn00010/fluxes.json` - flux values used for the supplementary flux-overlay map.

Summary files are intentionally not included.
