# External Tool Comparison

This directory contains the publication-ready artifacts retained for the external visualization tool comparison.

## Included Artifacts

- `tool_comparison_matrix.png` and `tool_comparison.html` - rendered comparison matrix.
- `sammi_full.html` - SAMMI full-map export.
- `networkx_baseline.png` - NetworkX baseline visualization.
- `grohar_output.png` - Grohar visualization output.
- `metexplore_v2_visualization.png` - MetExplore V2 visualization output.
- `cave_d_glucose.svg` - CAVE visualization output.
- `fluxer_upload_model.xml` - SBML model for Fluxer GUI upload.
- `fluxer_e_coli_core.svg` - Fluxer visualization output, retained as the primary high-quality export.
- `fluxer_e_coli_core.png` - Fluxer visualization output as a raster preview/export.
- `model_for_fluxer.json` - COBRA JSON copy of the same model retained for compatibility with tools that accept COBRA JSON.

Flux/flow files, duplicate CSV tables, summary files, and non-NAViFLuX workflow scheme artifacts are intentionally not included in this publication bundle.
