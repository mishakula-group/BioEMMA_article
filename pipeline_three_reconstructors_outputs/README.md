# Pipeline outputs for three metabolic reconstructors

This directory contains the retained outputs from the article Scenario III run:
one E. coli sequencing run was processed once, then gapseq, ModelSEEDpy, and
Reconstructor were launched in parallel and evaluated with MEMOTE.

## Dataset and run parameters

- Organism: `Escherichia coli` str. K-12 substr. MG1655
- SRA run: `SRR13921546`
- BioProject: `PRJNA706563`
- WDL used: `00_workflow/gapseq_modelseed_reconstructor_from_sequences.wdl`
- Cromwell/BioUML input JSON:
  `00_workflow/e_coli_gapseq_modelseed_reconstructor.inputs.json`
- Medium file: `../data/M9_vit_aa.csv`
- Reconstructor medium: the same ModelSEED compounds as comma separated
  extracellular IDs with `_e` suffix, stored in the input JSON
- Reconstructor `file_type`: `1`, amino-acid FASTA generated by Prokka
- Gram setting: `negative`
- KEGG pathway set: `00010,00020,00030`

The raw FASTQ files are not stored in this repository. To rerun the workflow,
download `SRR13921546_1.fastq.gz` and `SRR13921546_2.fastq.gz`, then replace the
two `PATH/TO/...` placeholders in the input JSON.

Example from the repository root:

```powershell
java -jar cromwell.jar run wdls\workflows\gapseq_modelseed_reconstructor_from_sequences.wdl -i pipeline_three_reconstructors_outputs\00_workflow\e_coli_gapseq_modelseed_reconstructor.inputs.json
```

## Contents

- `00_workflow/` - WDL and input JSON for the article Scenario III run.
- `02_raw_read_qc/` - FastQC reports for the input read pairs.
- `03_trimmed_reads_and_qc/` - processed paired reads, fastp report, and FastQC
  reports after trimming.
- `04_assembly/` - SPAdes assembly outputs.
- `05_assembly_qc/` - QUAST assembly quality report.
- `06_annotation/` - Prokka annotation outputs.
- `07_gapseq_model/` - gapseq model outputs and reaction/pathway/transporter
  tables.
- `08_modelseed_model/` - ModelSEEDpy reconstructed model.
- `09_reconstructor_model/` - Reconstructor reconstructed model.
- `10_memote_reports/` - MEMOTE reports for the three reconstructed models and
  the comparison report used as Supplementary Figure S10.
- `11_bioemma_maps/` - note about the raw WDL map archive from this run. The
  publication maps are stored under `../results/figure_03/map00020/`.
- `12_final_models/` - renamed final models for direct use.
- `FILES.csv` - file inventory for this directory.
